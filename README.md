# jeremydevdesign.github.io

Root GitHub Pages site for the developer account.

- `app-ads.txt` - authorised ad sellers (Google AdMob), required at the domain
  root that the App Store listing's Marketing URL points to
- `index.html` - developer page linking to each app's support site

Each app's support and privacy pages live in their own repositories
(`ipptencik-support`, `firenow-support`), served under this domain.
